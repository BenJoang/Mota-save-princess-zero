## 游戏亮点

**《魔塔救公主·零》**，又名「魔塔救公主零」，也被称为「90」，是由大傻水工作室使用 **RPG Maker XP** 制作的魔塔游戏。脚本与玩法在借鉴《新新魔塔》特征的同时，加入了以**石像组合**为核心的设计。

| 🗿 十种石像 | ⚡ 主动 × 被动 | 🏰 经典中的新变化 |
| :--- | :--- | :--- |
| **10 种不同石像**，构成游戏的核心玩法。 | **5 种主动 + 5 种被动**，通过不同组合发挥意想不到的效果。 | 在熟悉的魔塔探索中，体验石像技能、战斗与地图交互。 |

**战斗不止看攻防。** 敏捷、暴击、怪物特殊能力与石像效果共同影响战局：蝙蝠的伤害回复、岩兽的攻防交换，或是史莱姆的敏捷提升，都能带来不同的战斗思路。

> **版本进度**：已发布[一周目正式版 v1.0.0](https://github.com/BenJoang/Mota-save-princess-zero/releases/tag/v1.0.0)。剧情设计分为一、二周目，二周目正在制作中，发布时间以之后的 [Releases](https://github.com/BenJoang/Mota-save-princess-zero/releases) 公告为准。

## 下载与开始

### 01 · 获取游戏

前往 **[最新版本下载页 →](https://github.com/BenJoang/Mota-save-princess-zero/releases/latest)**，在页面底部的 **Assets** 中选择 Windows 游戏压缩包。

当前 v1.0.0 的游戏包名称为：

```text
Mota-save-princess-zero-v1.0.0-Windows.zip
```

### 02 · 解压并启动

1. 将游戏压缩包**完整解压到一个单独的文件夹**。
2. 安装包内 `★必须安装的字体★` 文件夹中的两款字体：`STXINGKA.TTF`、`华康布丁体.TTF`。
3. 在解压后的游戏目录中运行 **`Game.exe`**。
4. 需要了解角色技能、怪物属性与相关机制时，可查阅包内的 **`信息说明.txt`**；其中包含技能获取位置等攻略信息，建议按需阅读。

> 请在解压完成后运行游戏，避免直接在压缩软件内启动。

### 03 · 遇到问题

<details>
<summary><b>应该下载游戏包，还是 Source code？</b></summary>

请选择 Assets 中的 **Windows 游戏压缩包**。`Source code (zip)`、`Source code (tar.gz)` 以及仓库的 `Code → Download ZIP` 是仓库快照，不是可直接游玩的游戏发行包。

</details>

<details>
<summary><b>文字显示异常或无法正常启动？</b></summary>

先确认游戏已完整解压，并按照包内说明安装所需字体。如果仍有问题，请通过 [Issues](https://github.com/BenJoang/Mota-save-princess-zero/issues) 反馈，并附上游戏版本、Windows 版本、报错截图及复现步骤。

</details>

<details>
<summary><b>想报告 Bug、提出建议或分享游玩反馈？</b></summary>

欢迎提交 [Issue](https://github.com/BenJoang/Mota-save-princess-zero/issues/new)。报告 Bug 时，建议说明所在楼层、触发条件、预期表现与实际表现；能够复现问题的截图或存档也会有帮助。

</details>
